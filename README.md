# EB Billing System – Test Automation Suite

This project contains a custom-built test automation framework using **Selenium**, **TestNG**, and **Java**, written to demonstrate test coverage for a web-based billing system.

## ✅ Test Cases Implemented
- `LoginTest`: Validates user login functionality
- `BillCalculationTest`: Verifies dynamic electricity bill calculation logic
- `PreviousBillsTest`: Confirms historical bills are shown correctly

## 🧰 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## 💻 How to Run
1. Clone this repo
2. Open in IntelliJ
3. Run the tests via `testng.xml`
